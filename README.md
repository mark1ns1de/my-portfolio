# Моя візитка (my-portfolio)

Простий вебсайт-візитка з інформацією про мене, моїми навичками та контактами.
Проєкт створено в межах домашнього завдання «Git і GitHub для безпечного вайб-кодингу» (ITStep, Модуль 5).

## Використані технології

- HTML5
- CSS3
- Git та GitHub
- Cursor (AI-агент для генерації коду)

## Як запустити

1. Склонуйте репозиторій:
   ```bash
   git clone https://github.com/mark1ns1de/my-portfolio.git
   ```
2. Відкрийте папку `my-portfolio`.
3. Відкрийте файл `index.html` у будь-якому браузері (подвійний клік по файлу).

## Нова функціональність: перемикач теми

У гілці `feature/theme-toggle` за допомогою AI-агента додано перемикач світлої та темної теми:

- кнопка «🌙 Темна тема / ☀️ Світла тема» у правому верхньому куті сторінки;
- темна тема змінює кольори фону, картки, тексту та плашок навичок;
- обрана тема зберігається в `localStorage` і відновлюється після перезавантаження сторінки.

## Безпека

Секретні дані (API-ключі, паролі) зберігаються у файлі `.env`, який додано до `.gitignore`,
тому він не потрапляє до репозиторію. У проєкті використовується лише вигаданий демонстраційний ключ.

## Структура проєкту

```
my-portfolio/
├── index.html   # сторінка візитки
├── style.css    # стилі сторінки
├── script.js    # логіка перемикача теми
├── .gitignore   # файли, які Git ігнорує (.env)
└── README.md    # опис проєкту
```
